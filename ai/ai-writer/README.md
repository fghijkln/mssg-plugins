# ai-writer

AI 写作助手插件（type: ai）。

## 安装

在织网 App 的「🧩 扩展商店」里安装。装好后，编辑文章时点「🤖 AI」就能用。

## 动作

| 动作 | 说明 |
|------|------|
| ✍️ 续写 | 按原文风格续写 |
| ✨ 润色 | 改错别字、优化表达 |
| 📝 扩写 | 增加细节和例子 |
| 📌 起标题 | 生成 5 个标题 |
| 📄 写摘要 | 100 字摘要 |

## 自定义

`ai-writer.json` 里的 `actions` 可以自己加：

```json
{
  "id": "mymode",
  "label": "😎 我的模式",
  "system": "系统提示词（可选）",
  "prompt": "用户提示词模板，用 {{content}} 代表编辑器里的文章"
}
```

## 需要配置

App 里要先配好 AI 接口（AI 助手里的设置）：API 地址、Key、模型，兼容 OpenAI 接口格式。
